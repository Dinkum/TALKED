# A Tiny Language Model Can Read Neural Sockets

Specialist models emit tiny typed packets. A small transformer receiver trained on source-domain packets reads unrelated held-out specialist packets at `87.7%` mean state accuracy across a three-seed battery, versus `14.6%` with no packet and `4.7%` with shuffled packets. Packet-only state reading reaches `89.4%`.
