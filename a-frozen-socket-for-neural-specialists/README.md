# A Frozen Socket for Neural Specialists

A tiny frozen packet ABI lets unrelated neural specialists plug in through local encoders only. Graph shortest-path, max-index, counting, ranking, and a different retrieval architecture all transfer through a socket trained only on checksum and retrieval, while a matched random socket does not recover the trained socket's reusable semantics.
